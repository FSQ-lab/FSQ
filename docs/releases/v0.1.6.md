# FSQ v0.1.6

FSQ v0.1.6 is an alpha maintenance release focused on Provider configuration, Workspace diagnostics, and Android context collection.

## Highlights

- The Control Plane shows model status for a saved GitHub Copilot session and supports switching that session's model (#7).
- Workspace Doctor can inspect the registry in a read-only Workspace without trying to create a writable lock (#5).
- Android context collection removes an unused foreground-activity probe. This eliminates the repeated approximately 10-second probe observed on the affected device; it is not a universal latency guarantee (#8).
- The indirect frontend dependency `source-map-js` is updated from 1.2.1 to 1.2.2 (#1).

## Install

```bash
python -m pip install --upgrade fsq-agent==0.1.6
```

Python 3.11 through 3.13 remain the declared supported versions. Host applications, browsers, devices, ADB, and Appium services remain external prerequisites.

## Compatibility and upgrade guidance

This release does not intentionally change public runtime contracts or Workspace formats. Existing v0.1.5 Workspaces do not require reinitialization. A saved GitHub Copilot session is required before its model status can be loaded or its model can be switched.

After upgrading, run `fsq doctor` for the intended Workspace and platform before executing a Case. Android context still reports current-package metadata, while the optional current-activity field remains unavailable rather than triggering a separate probe.

## Privacy and evidence

Run evidence can contain screenshots, UI trees, logs, metadata, reports, and application data. Review and redact artifacts before sharing them, and never publish Provider secrets, tokens, cookies, private URLs, device identifiers, or unreviewed Run data.
