# FSQ v0.3.2 release preparation

Date: 2026-10-21. Python distribution: `fsq-agent` 0.3.2. FSQ remains alpha.
This document prepares a release identity and notes; it does not establish a
`v0.3.2` tag, GitHub release, PyPI publication, or deployed Website revision.

## Changes since the 0.3.1 preparation

- [Android input and context fixes (#39)](https://github.com/FSQ-lab/FSQ/pull/39):
  text-entry readback can recognize the same uniquely resource-bound control
  after keyboard or layout changes. It retains exact text, package, class,
  resource, editability, and uniqueness checks. Positional locators do not
  gain permission to follow a different input. Masked/unreadable values,
  ambiguous or disabled targets, mismatches, and lost identity cannot produce
  success; no alternative target or implicit write retry is introduced.
  Initial device context also retries one read for the specifically identified
  `ApplicationSharedMemory not initialized` backend failure. Other errors
  propagate normally; no application action is repeated by that recovery.
- [Public presentation and onboarding (#41)](https://github.com/FSQ-lab/FSQ/pull/41):
  synchronized English/Chinese README and guides with the Landing Page, while
  preserving the Website headline and white/green visual system. Coding Agent
  and FSQ UI are equal Quick Test entry paths with expandable setup, visible
  prerequisites, and private Provider/model setup. The shared example searches
  for FSQ-lab/FSQ, follows its About website link, and verifies both homepage
  headlines. Case management and deterministic replay remain separately chosen
  advanced workflows. Star and sanitized-feedback links follow the trial.
  The current Android demonstration, matching explanatory screenshots, captions,
  cover, social image, and source records replace the active old presentation.
  Native Website playback starts only after activation; controls, captions,
  keyboard focus, and fallback viewing links remain available.
- [README demo simplification (#42)](https://github.com/FSQ-lab/FSQ/pull/42):
  removed the duplicate YouTube cover-image links from both READMEs. The GitHub
  inline video, YouTube/caption/provenance text links, and three story images
  remain. Website playback and its cover asset are unchanged by that trim.
- Python metadata and its exact distribution-contract assertion advance to
  0.3.2. The private npm package retains its independent 0.1.0 version.
  This release-preparation edit does not change runtime code, dependencies,
  public interfaces, or configuration.

These changes are established by repository history following the merged
0.3.1 preparation (#38). The comparison references below anticipate release
tags, rather than claiming an earlier package or tag was published.

## Upgrade after publication

Once 0.3.2 is published and obtainable from the package index used by your
Python environment, upgrade with:

```bash
python -m pip install --upgrade fsq-agent==0.3.2
```

Project-local Skills are copies. Package installation or a host reload alone
does not refresh them. From your Coding Agent project, explicitly run:

```bash
fsq init --agent skill
```

Review installer updates, backups, and conflicts under `.agents/skills/fsq/`,
then reload Skill discovery or start a new Coding Agent session.
`--no-overwrite` preserves an existing copy. No Workspace reinitialization or
Provider reconfiguration is required solely for this version change.

Continue through either [Coding Agent or FSQ UI](../getting-started.md).
Quick Test uses the dedicated user-level Workspace, returns inspectable
results/evidence, and does not save a formal Case or automatically replay one.
Python 3.11+, a configured supported Provider and selected model, and
[platform-specific prerequisites](../platform-prerequisites.md) still apply.
Never paste Provider credentials into Coding Agent chat.

## Validation and publication status

The preparation uses a failing exact-version contract check before the metadata
bump, followed by the focused distribution-contract module, Ruff lint/format,
and diff checks. Results belong to the final identified source snapshot and its
external validation evidence; these instructions do not assert a passing result.
Earlier PR, release, or local results are historical and are not final 0.3.2
validation evidence.

Final frontend compilation, wheel and sdist creation, a wheel rebuilt from the
sdist, metadata/resource comparisons, fresh source-free installed-package smoke
tests, and independent review are pending integration verification. The smoke
must use the built artifact outside the source checkout, including both console
entry points, platform presets, copied Skill resources, and packaged static
serving. These checks do not replace a real target or Provider test.

The complete 0.3.2 Python/frontend CI and supported-platform matrix are pending.
No all-platform live execution, clean public-index end-to-end first-use run, or
successful release pipeline is claimed. Building a local wheel does not prove
public installation availability.

[Media provenance](../media/quick-test-demo-provenance.md) records the matching
Android Run's producer as FSQ 0.2.1; it is not a recording of 0.3.2. Source commit,
capture/export timestamps, and some runtime conditions remain unestablished.

whole-video privacy/security, complete caption synchronization and muted
comprehension, three-person new-user acceptance, public first-use, and deployed
