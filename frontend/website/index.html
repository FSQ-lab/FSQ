FSQ — Fully Self Quality

Describe a goal. Test the real app.

FSQ is open-source alpha software for goal-driven testing of real user interfaces. It records screenshots, interface state, and events so you can inspect the evidence. A run may return a Case; review it before making the separate choice to replay it.

Choose either Quick Test path

Python 3.11+, a supported configured Provider and selected model, and platform prerequisites are required. Quick Test needs no manual project Workspace and does not save a formal Case or perform Strict Replay.

Coding Agent

Add the FSQ Skill, reload the Coding Agent, and ask it to run your Quick Test goal. Never paste Provider credentials into Coding Agent chat.

Open Coding Agent setup

FSQ UI

Install fsq-agent, run fsq ui, and choose Quick Test. Configure your Provider and model privately in Settings.

Open FSQ UI setup

Try a complete user journey

In a selected Web browser, search for the FSQ-lab/FSQ GitHub repository, follow the website link in About, and verify both “Describe a goal.” and “Test the real app.” on the destination page. Only browse public pages; do not sign in or submit forms. Inspect the result and captured page evidence.
