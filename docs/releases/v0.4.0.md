# FSQ v0.4.0

`fsq-agent` 0.4.0 pins `appium-connect-agent==0.1.5` from PyPI. Once both packages are published, upgrade with `python -m pip install --upgrade fsq-agent==0.4.0`. Existing workspaces do not require a configuration migration for these changes.

- **macOS native input:** Finder-anchored sessions and sessions whose logical target differs from the WDA host dispatch business input through the SDK's native desktop API. FSQ checks the real foreground application and validates live pointer hits before dispatch. Native wheel deltas must be integer-valued; a successful dispatch does not establish that an edit was committed or saved.
- **macOS observations and recovery:** Context reads main-display geometry without requesting WDA source. After foreground loss, reactivate the original explicit bundle with `new_session=false`; use `auto` only to discover the current foreground. A transient Mac2 screenshot failure in Finder-anchored mode can fall back to a bounded local capture; this does not extend to AI visual tools. Safe timeout and capture diagnostics survive evidence failures, and explicit teardown can still settle pending or uncertain sessions on their owner thread.
- **Planning and verification:** Resolve general categories from live UI evidence instead of inventing exact labels. Choose a standard variant only when the user leaves it open and explicit constraints are met. For edits and derived values, read back the committed state. Reuse a healthy macOS session for work across documents when no application rebind is needed.

Broad-32 v2 on the frozen development candidates recorded 22/32 strict-upstream passes. This is not a score for the final public FSQ 0.4.0 / SDK 0.1.5 distributions. The local candidate checks do not replace clean public-package installation or release verification.
