# FSQ v0.3.8 release preparation

`fsq-agent` 0.3.8 pins `appium-connect-agent==0.1.2` and `lxml==6.1.0`. This document does not establish a tag or publication.

macOS uses direct Appium Mac2 by default. Eligible owned sessions for Keynote, Pages, Numbers, and LibreOffice can use a Finder-anchored fallback with FSQ-owned native Accessibility. In both modes keyboard input uses Appium `macos: keys`; the Finder anchor uses the session-level Device after verifying foreground focus. Switching between fallback and direct mode rebinds the Mac2 session. Existing workspace configuration needs no migration.

Finder-anchored sessions can collect a local screenshot when WebDriverAgent capture fails. Local capture may require macOS Screen Recording permission. When lossless recovery has released all owned resources but recreation fails, a later action may recreate the session; the failed business action is not replayed.

Rich document and slide canvases can use explicit screenshot-guided coordinates and keyboard editing when the control is not exposed through Accessibility and the task permits coordinate targeting.
